# HAN REJUVE 線上預約系統

手機、電腦都能用的美容預約網站，包含會員預約前台與管理後台。
技術：Python Flask + SQLite 資料庫（資料存在 `hanrejuve.db`）。

## 下載與試用

**1. 安裝 Python 3.10 以上版本**
到 https://www.python.org/downloads/ 下載安裝。Windows 安裝時請勾選 **Add Python to PATH**。

**2. 下載這個專案**
在 GitHub 頁面按綠色的 **Code → Download ZIP**，解壓縮到任一資料夾；
或用 git：`git clone <專案網址>`

**3. 啟動**
- **Windows**：雙擊資料夾裡的 `run.bat`（會自動安裝需要的套件並啟動）
- **Mac / Linux**：在資料夾裡打開終端機，執行
  ```
  python3 -m pip install -r requirements.txt
  python3 app.py
  ```

**4. 打開網站**：瀏覽器輸入 http://127.0.0.1:5000
同一個 Wi-Fi 下的手機可用 `http://<這台電腦的 IP>:5000` 測試。

**5. 管理員登入**
第一次啟動會自動建立一個全新的資料庫和管理員帳號，
登入 Email 與密碼寫在資料夾裡的 `admin_initial_password.txt`。
登入後可到「我的帳號」改密碼，並刪除該檔案。

> 試用時的資料（會員、預約）只存在你自己電腦的 `hanrejuve.db`，不會影響正式網站。
> 想重新開始，只要關掉網站、刪除 `hanrejuve.db` 再啟動即可。

**注意**：`hanrejuve.db`、`secret_key.txt`、`admin_initial_password.txt` 含有個資或機密，
已列在 `.gitignore`，請勿上傳到 GitHub。

## 功能

**全站**
- 右上角「EN / 中文」按鈕切換英文與中文介面（翻譯對照表在 `i18n.py`，新增介面文字時請一併加上英文）
- 所有表單送出的簡體字會自動轉成繁體（使用 OpenCC）；密碼與 Email 不轉換

**會員前台**
- 首頁：品牌介紹、服務項目（主項目點開看子項目；不顯示時長與價格）
- 註冊 / 登入（Email 格式檢查、馬來西亞 +60 手機號碼）
- 新會員註冊自動收到新人體驗券（後台勾選「新人禮」的優惠券）
- 線上預約：選服務 → 選優惠券（選填）→ 選日期 → 選時段，送出前需勾選預約須知
- 收件箱：活動公告、優惠券信件，未讀數字提示
- 我的優惠券：可使用 / 已使用 / 已過期；預約取消時優惠券自動退回
- 我的預約、我的帳號

**管理後台**（`/admin`）
- 總覽：今日預約、待確認數、未來 7 天、會員數、本月營收（有用券以體驗價計算）
- 預約管理：依日期 / 狀態 / 顧客搜尋，確認、完成、取消、未到店，內部備註
- 新增預約：電話或現場客人（電話與會員相同會自動連結）
- 服務項目：主項目 / 子項目；預計時長（計算空位用）與參考價格（營收統計用）不顯示給客人
- 優惠券：體驗價、適用項目、有效天數、海報、新人禮、每人限領一次
- 公告信件：發佈活動公告（可附海報）、發送優惠券給全部或指定會員
- 會員：列表、搜尋、預約紀錄、優惠券、累計消費、重設密碼、設定管理員
- 營業設定：店名、電話、地址、營業時間、時段間隔、同時段人數（床位/美容師數）、
  可預約天數（0 = 不限）、最少提前時間、取消期限、自動確認、預約須知、每週公休、特定店休日

## 正式上線

目前是在自己電腦執行。若要讓客人從網路預約，需要部署到主機（例如 Render、Railway、
PythonAnywhere 或自己的 VPS），並設定網域與 HTTPS。部署時：
- 用 `gunicorn app:app`（Linux）或 `waitress-serve app:app`（Windows）取代 `python app.py`
- 設定環境變數 `HAN_SECRET`（一串隨機字元）與 `HAN_DB`（資料庫路徑，需放在會保留的磁碟）
- 定期備份 `hanrejuve.db` 與 `static/uploads/`（上傳的海報圖片）
